# 亲缘

亲缘通常被讲成血缘的责任、家庭的神圣、对自己人天生的亏欠。

## 它原来是什么

照料与自己共享更多基因的个体，会让这些基因更可能留到以后。不照料的差异更容易消失。留下来的是一种偏向：离自己的基因更近的个体，更容易得到保护和资源。

这不是一条先于生命的家法。没有生命的时候，石头掉在地上，没有亲属，也没有亏欠。

## 它如何被神圣化

偏向被讲成义务之后，不偏向就成了邪恶，而不只是另一种没被留下的差异。家族、血统、民族接着被说成高于可核对的事实。人的特殊性常常从这里出发：我的人是特殊的，所以我的人的道德也是特殊的。

## 在这套文明里

亲缘可以被描述，也可以被当作合作会发生的事实。它不能单独成为一项提案必须通过的理由。一项安排若只因为“自己人”就豁免验证，它就回到了被神圣化的道德，而不是这一卷所接受的事实。
