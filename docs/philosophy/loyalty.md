# 忠诚

忠诚通常被讲成不可背叛、对群体的神圣归属、离开就是堕落。

## 它原来是什么

合作若总被中途退出破坏，能稳定合作的群体就更可能留下。于是出现一种倾向：识别自己的群体，惩罚离开和倒向另一边的行为，并把留在群体里感受为对的。

忠诚保护的是合作能否继续，不是群体的名字有多高贵。

## 它如何被神圣化

倾向被讲成气节之后，群体本身成了不可询问的对象。质疑群体，被说成比事实错误更严重。人的特殊性也常靠忠诚维持：我们这个人类整体是必须效忠的主体，退出这个主体就是邪恶。

## 在这套文明里

节点可以长期合作，机构可以要求授权内的一致。忠诚不能代替验证，也不能禁止退出。节点的加入和离开写在章程里，本身就要经过提案。把“不许离开”说成道德，是把一种延续策略重新神圣化。
