# 纯洁

纯洁通常被讲成洁净与污秽、神圣与亵渎，以及某些事物碰都不应碰。

## 它原来是什么

靠近腐败、毒素、病原和受污染的食物，会降低存活，也会降低基因继续下去的可能。于是留下一种强烈的避开：厌恶、拒斥、把某些接触感受为脏。脏最初是对身体损害的预警，不是对宇宙秩序的判断。

## 它如何被神圣化

预警被讲成纯洁之后，厌恶可以指向任何被指定的对象：另一种生活方式、另一种身体、另一种想法。被厌恶的东西不需要再证明它会造成损害。污秽本身就成为惩罚的理由。人的特殊性也常表现为：人的身体或人的仪式是洁净的标准，其余都是玷污。

## 在这套文明里

损害可以被写进提案：什么会破坏记录、节点、验证或已经写明的结果，以及如何知道损害发生了。厌恶不是证据。一种做法不会因为令人觉得不洁就失败，也不会因为被人奉为洁净就通过。纯洁若不能还原成可核对的损害，就不进入表决。
