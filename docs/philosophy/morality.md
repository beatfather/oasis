# 道德，是最古老的谎言

生命出现之后，多了一条可以被淘汰的标准：一种差异若不能帮助基因延续，这种差异就从以后的世界里消失。自然选择不奖励善良，也不惩罚邪恶。它只留下更能把自身延续下去的差异。

于是一些倾向被留下来。照料和自己相近的个体。回报帮助过自己的个体。留在能合作的群体里。对同伴受到的损伤做出反应。发出别人敢相信的信号。躲开会损害身体的东西。

这些倾向后来被叫作道德，并被说成神圣的义务，好像它们先于生命、高于事实。这个顺序是谎。道德是延续策略被命名之后的样子。名字可以留下。神圣不能留下。

下面每一页只处理一种被叫作道德的倾向：它在延续里做了什么，后来如何被神圣化，以及这一文明还把它当成什么。

- [谦虚](./humility)：把优势藏起来，避免成为出头的那一个。
- [亲缘](./kin)：偏向和自己更近的个体。
- [互惠](./reciprocity)：回报帮助，记住亏欠。
- [忠诚](./loyalty)：留在合作的群体里。
- [同情](./compassion)：对损伤做出反应。
- [诚实](./honesty)：发出别人敢相信的信号。
- [纯洁](./purity)：躲开会损害身体的东西。
