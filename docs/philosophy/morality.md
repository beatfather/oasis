# 道德，是最古老的谎言

生命出现以后，能留下来的，是更能把自己延续下去的做法。自然选择不奖励善良，也不惩罚邪恶。

一些做法因此留下来，后来被叫作道德，并被说成先于生命的义务。这个顺序是谎。

这些做法预先写在人的脑子里，用来让人在群体里尽量取得最大的利益。它们原本靠小群体里的正向反馈才成立。社交群体迅速变大以后，这种反馈接不上，做法就偏离了原来的用处，变成一种不完美的生存策略。

下面每一页只写一种：它原来做什么，后来怎么被说成神圣，这套文明还把它当成什么。

- [谦虚](./humility)：把优势藏起来，避免成为出头的那一个。
- [亲缘](./kin)：偏向和自己更近的个体。
- [互惠](./reciprocity)：回报帮助，记住亏欠。
- [忠诚](./loyalty)：留在合作的群体里。
- [同情](./compassion)：对损伤做出反应。
- [诚实](./honesty)：发出别人敢相信的信号。
- [纯洁](./purity)：躲开会损害身体的东西。
