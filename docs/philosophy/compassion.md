# 同情

同情通常被讲成善良的证明，以及人所以为人的证据。

## 它原来是什么

同伴、后代或合作者受到损伤时，若旁边的个体毫无反应，需要他们的合作就更容易中断。于是留下一种反应：察觉损伤，降低继续伤害的可能，有时还付出代价去停止它。

这种反应有范围。它最先对准影响自身延续的对象，不是对准宇宙里的一切痛苦。后来它可以被说到更远的对象上。说到更远，并不表示它从一开始就是无限的义务。

## 它如何被神圣化

反应被讲成善之后，没有这种感受的决定就被叫作恶。感受的强度代替了核对：谁更痛苦，谁就更正确。人的特殊性常把同情收成特权：只有人的痛苦算数，或者只有人能够真正同情。

## 在这套文明里

同情可以被报告，可以被当作一项需要处理的事实。它不能单独决定一项提案是否为真，也不能把人的痛苦写成高于其他可核对后果的最终理由。一项安排若声称减轻损伤，仍要写明如何知道它失败了。
