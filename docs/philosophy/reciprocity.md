# 互惠

互惠通常被讲成公平、报恩、欠债还钱，以及“人应当如此”。

## 它原来是什么

一个个体若帮助另一个个体，并在以后得到回报，双方都更可能留下来。只索取、不回报的差异，会在重复相遇里被避开，于是更难延续。留下来的是一种计算：记住谁帮助过，谁亏欠过，下一次是否继续合作。

公平感是这种计算的感受形式。它不是宇宙先写好的等式。

## 它如何被神圣化

计算被讲成正义之后，每一次交换都要符合一种高于事实的公平。谁定义公平，谁就占有了道德。不能被核对的“应该”，代替了“这次合作是否还能延续、结果是否写得清”。

## 在这套文明里

互惠可以出现在节点之间，也可以出现在提案的代价和收益里。它必须写清交换的是什么、如何验证、失败了如何停。不能验证的亏欠，不构成通过一项提案的理由。
