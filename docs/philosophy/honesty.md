# 诚实

诚实通常被讲成心灵的纯洁、撒谎即罪恶、真理是道德命令。

## 它原来是什么

合作依赖信号。信号若经常和以后发生的事对不上，别人就不再根据它行动。发出不可信信号的个体，会被排除出下一次合作，于是这种差异更难延续。留下来的是一种约束：在会被再次遇见的关系里，让说过的话和以后的事实大体一致。

这不是因为语言神圣。这是因为不可信的语言会失去作用。

## 它如何被神圣化

约束被讲成品德之后，真话成了一种身份，而不是一次可以核对的对应。人被说成唯一能承担真理的物种。说了符合身份的话，即使对不上事实，也仍被叫作诚实。

## 在这套文明里

诚实就是可核对。提案、表决和执行记录必须让后来的人能对上当时写下的话。对不上，就改说法，不改记录。这和 [科学](/values/science) 是同一条要求。诚实不是人的美德专利，而是任何还想合作的信号都必须满足的条件。
