# 务实

务实，在这里指：从现在办得到的下一步做起，并把这一步的结果当成下一步的依据。

## 含义

务实不是降低标准，也不是拒绝长远安排。它拒绝只存在于措辞里的方案：没有执行者、没有资源、也没有办法知道做成没有。

一个长远目标若要进入章程，就要拆成 Oasis 现在就能交付表决的提案。

## 在决定里怎么用

议事优先处理写清了下一步的提案。下一步要小到可以执行，也要完整到可以验证。做完这一步，再决定要不要有下一步。

暂时做不到的部分写成后续提案，不写进这一步的授权里。

## 配不上这个词的做法

用更大的愿景掩盖这一步没有着落。也要避免相反的做法：因为一步很小，就把它说成不需要验证。
