# 科学

科学，在这里指：一个说法要能被检验。检验失败，就改说法，不改记录。

## 含义

科学不是“听起来先进”。它要求主张分成可以核对的部分：预测是什么，证据出现在哪里，什么结果会推翻它。

Oasis 接受未完成的说法。未完成和不可检验不是一回事。未完成的说法要标明还缺哪一次检验。

## 在决定里怎么用

提案如果声称某件事会带来某个结果，就必须写上如何知道它错了。没有失败条件的好处，不进入表决。

表决通过也不能把一个说法变成事实。执行之后仍要按提案里的验证方式核对。对不上，就记下来，并可以提出撤回。

## 配不上这个词的做法

用身份、声量或节点数量代替证据。节点可以决定做不做一件事，不能投票把一次失败的检验改成成功。
