# 探索

探索，在这里指：给还没有结论的问题留出尝试的位置，并把尝试的边界写清楚。

<RocketSpace />

## 含义

探索不是例外于章程。一次探索仍然是提案：要尝试什么、尝试到哪里为止、什么信号说明该停、结果如何记入 Oasis 的记录。

未知本身不是反对的理由，也不是通过的理由。

## 在决定里怎么用

新的节点规则、新的机构职责、新的验证方式，都可以先以有期限的探索进入表决。期限结束，结果公开，再决定把它写进常设条款、修改之后再试，或者停止。

探索的授权到期就失效。继续做，需要新的提案。

## 配不上这个词的做法

把已经决定的事改名叫探索，用来逃避验证。也要避免把一切未知都挡在表决之外，使文明只重复已经写过的句子。
