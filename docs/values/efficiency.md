# 效率

效率，在这里指：同样的结果，消耗更少的时间、注意力和资源；若消耗相同，就取更可核对的那一种做法。

## 含义

效率不是赶工，也不是省略记录。省掉验证的速度，不记成效率。一次表决若因为材料不齐而重来，比事先写清更慢。

节点的时间也是成本。能一次写清的提案，不拆成一串互相依赖、却又无法单独验证的投票。

## 在决定里怎么用

两条都能达到同一结果时，取步骤更少、记录更短、失败更容易发现的那条。步骤少但不能回答“如何知道做错了”，就回到科学那一条，不因为短而通过。

执行机构在授权范围内可以选择更省的做法。范围本身不能为了省事而扩大。

## 配不上这个词的做法

为了显得慎重而重复没有新信息的程序。也为了显得果断而跳过唯一能发现错误的那一步。
