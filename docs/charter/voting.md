# 投票节点

文明的表决由加密货币投票节点完成。一个节点是一份投票权，不是一个论坛账号。

## 节点是什么

节点持有投票权，并在一次表决中给出可验证的一票。投票权来自节点本身，不来自发言次数，也不来自某人在 Oasis 的职务。

职务和投票权分开。执行机构的人可以说明提案，不能用职务代替节点投票。

## 一次表决如何成立

表决只处理已经通过议事、并写清验证方式的提案。节点在规定时间内签名投票。时间结束后，按已提交且可验证的票计结果。

未投票不记成反对，也不记成赞成。弃权就是缺席。

通过的提案进入执行。未通过的提案回到议事，可以改写后再提，不能直接执行。

## 节点的更替

节点可以新增，也可以退出。新增和退出本身也是提案：写清哪一个节点加入或离开、投票权如何变化、变化从哪一次表决开始生效。

生效之前，仍按旧的节点名单计票。
