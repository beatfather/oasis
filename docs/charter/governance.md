# 政府结构

Oasis 的政府只做章程写明的事：接收提案，交付执行，并公开留下可核对的记录。

## 议事

提案先进入议事。议事不直接动用力量，它决定一件事是否交付表决。

进入表决的提案必须写清三件事：要改变哪一条、改变之后如何验证、失败了如何撤回。写不清的提案停在议事，不进入节点投票。

## 执行

表决通过之后，执行机构按提案写明的范围行事。执行机构不能把一次授权解释成相邻的另一件事。范围之外的行动需要新的提案。

## 记录

每一次提案、表决和执行都记在公开记录里。记录至少要能回答：谁提出、哪些节点通过、执行了什么、结果是否符合提案里的验证方式。

记录归 Oasis 存档。节点可以复制，不能把另一份未公布的文本当成正本。
